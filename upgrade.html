維護原則

未來有新版本，會自動更新我的 1shop 嗎？

不會。建立平台讀取 GitHub 上的正式版本清單，按「自動升級」後即可取得新版完整代碼，再自行貼回 1shop。這樣不會未經驗收就更改商店前台。

新增專輯／商品類別之後，怎麼保留？

先在 1shop 儲存產生的新完整導覽程式；下一次以那一份為來源，就可保留所有新增連結。此工具也可保存多份原碼到瀏覽器，並下載 JSON 備份。

我換電腦會有相同專案嗎？

目前沒有自動雲端同步。請先匯出專案 JSON，到另一台電腦手動匯入。瀏覽器私人模式或清除網站資料可能會遺失本機草稿。

為什麼不能直接從 1shop 網址抓取我的設定？

網頁公開顯示的 DOM 可能沒有原始程式碼，也不一定含完整分類。為避免誤刪系列，使用 1shop 後台的原始「程式」區塊匯入才比較可靠。
